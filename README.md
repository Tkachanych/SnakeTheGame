## 🎮 Описание

«Змейка» — это современная веб-версия классической аркадной игры, в которой игрок управляет змеёй, собирает еду и старается не врезаться в стены или собственный хвост. Проект создан с использованием **React**, **TypeScript** и **HTML5 Canvas** для плавной отрисовки игрового поля.

Игра полностью адаптивна: она отлично работает как на настольных компьютерах (управление клавиатурой), так и на мобильных устройствах (свайпы и экранные кнопки).

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🎯 **Игровое поле** | Поле 20×20 клеток с сеткой и плавным Canvas-рендерингом |
| 🐍 **Анимированная змейка** | Градиентное тело, светящаяся голова с глазами |
| 🍎 **Еда с эффектами** | Свечение, радиальный градиент, вспышка при поедании |
| ⌨️ **Клавиатура** | WASD / Стрелки для движения, Пробел/Esc для паузы |
| 📱 **Сенсорное управление** | Свайпы + экранные кнопки-стрелки для мобильных |
| ⏸ **Пауза** | Мгновенная пауза и продолжение в один клик |
| 🔄 **Перезапуск** | Быстрый рестарт в любой момент |
| ⚡ **3 уровня сложности** | Лёгкий (180мс), Средний (120мс), Сложный (70мс) |
| 🏆 **Рекорды** | Лучший счёт сохраняется в localStorage |
| 📐 **Адаптивность** | Автоматическое масштабирование под любой экран |
| 🎨 **Современный UI** | Тёмная тема, градиенты, анимации, backdrop-blur |

## 🚀 Быстрый старт

### Предварительные требования

- **Node.js** >= 18
- **npm** >= 9

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/SnakeTheGame.git
cd SnakeTheGame

# 2. Установите зависимости
npm install

# 3. Запустите dev-сервер
npm run dev

# 4. Откройте в браузере
# http://localhost:5173
```

### Сборка для продакшена

```bash
# Сборка оптимизированного бандла
npm run build

# Проверка типов
npm run typecheck
```

Собранные файлы будут в папке `dist/`.

## 🎮 Управление

### 🖥 Настольный компьютер

| Клавиша | Действие |
|---------|----------|
| `↑` / `W` | Движение вверх |
| `↓` / `S` | Движение вниз |
| `←` / `A` | Движение влево |
| `→` / `D` | Движение вправо |
| `Пробел` / `Esc` / `P` | Пауза / Продолжить |
| `Enter` | Начать игру / Рестарт |

### 📱 Мобильное устройство

| Жест | Действие |
|------|----------|
| **Свайп вверх** | Движение вверх |
| **Свайп вниз** | Движение вниз |
| **Свайп влево** | Движение влево |
| **Свайп вправо** | Движение вправо |
| **Тап** | Пауза / Продолжить / Начать |
| **Кнопки-стрелки** | Альтернативное управление |

## 📖 Правила игры

1. **Цель** — набрать как можно больше очков, управляя змейкой
2. **Еда** (красный шар) — при поедании змейка удлиняется, а счёт увеличивается на **10 очков**
3. **Столкновение** — игра заканчивается при:
   - Врезании в стену
   - Врезании в собственный хвост
4. **Сложность** влияет на скорость движения змейки:
   - 🟢 **Лёгкий** — 180мс между шагами (медленно)
   - 🟡 **Средний** — 120мс между шагами (нормально)
   - 🔴 **Сложный** — 70мс между шагами (быстро)
5. **Рекорд** сохраняется автоматически и отображается на экране

## 📁 Структура проекта

```
SnakeTheGame/
├── index.html              # Точка входа HTML
├── package.json            # Зависимости и скрипты
├── vite.config.js          # Конфигурация Vite
├── tsconfig.json           # Конфигурация TypeScript
├── src/
│   ├── main.tsx            # Точка входа React
│   ├── App.tsx             # Главный компонент (Canvas, UI, оверлеи)
│   ├── index.css           # Глобальные стили и анимации
│   └── hooks/
│       └── useSnakeGame.ts # Хук с игровой логикой
└── dist/                   # Собранные файлы (после build)
```

### Ключевые файлы

| Файл | Описание |
|------|----------|
| `src/hooks/useSnakeGame.ts` | Вся игровая логика: движение змейки, столкновения, счёт, управление состоянием, клавиатурные обработчики |
| `src/App.tsx` | Рендеринг Canvas (змейка, еда, сетка), UI-оверлеи (старт, пауза, конец игры), обработка тач-событий, адаптивные кнопки |
| `src/index.css` | Tailwind-импорт, кастомные анимации (`fadeIn`), базовые стили body |
